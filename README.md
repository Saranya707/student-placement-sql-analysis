# 🎓 Student Placement SQL Analysis

## 📌 Project Overview

This project analyzes student placement data using SQL, SQLite and Python.  
The goal is to understand placement performance, salary trends, academic performance and skill-related patterns.

---

## 🎯 Problem Statement

Colleges maintain student academic, skill and placement data. Analyzing this data can help understand placement rates, salary patterns, department-wise performance and differences in skills among students.

---

## 💡 Solution

A SQLite database was created to store student placement data.

SQL queries were then used to retrieve, filter, sort, group and analyze the data. Python and Pandas were used to execute SQL queries and display the results in Google Colab.

---

## 💡 Key Insights

- The dataset contains 12 students.
- 8 students were placed and 4 were not placed.
- Overall placement percentage was 66.67%.
- The highest placement package was 16 LPA.
- SQL queries helped identify patterns across departments, skills, CGPA and placement outcomes.
- Skill comparisons showed differences between placed and non-placed students in this sample dataset.
